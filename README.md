# Curie
Curie is a project made for my wife so that she could take better notes with Obsidian. There is a multitude of functions included in Curie, such as, but not limited to:
- Sync with self-host server
- File storage and versioning
- File archiving and pruning
- AI-assisted knowledge domain analysis
- Citation generation and tagging
- Zotero integration
- and more...

This project is an ongoing effort to make note-taking better for my wife, and hopefully, by extension, for all of us.

Installation and features deep dive coming soon...
